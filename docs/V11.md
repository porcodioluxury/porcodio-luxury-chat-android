# v11 (Porcodio Luxury Chat)

## Media cifrati nelle chat super segrete
`PcSecretMediaCore` (AES-256-GCM a blocchi da 64 KiB, nonce = prefisso casuale + contatore, AAD con contatore e flag ultimo blocco: troncamenti e blocchi alterati falliscono; nome e tipo originali stanno dentro il file cifrato). Chiave = HKDF dell'intesa X25519 gia' usata per il testo, con etichetta propria (`PcSecret.mediaKey`).
* Invio: `SendMessagesHelper.prepareSendingDocuments` e `prepareSendingMedia` cifrano ogni file (anche foto/video della galleria, che escono come allegato `segreto-*.pcs`). Senza chiave scambiata, o se il file non si legge, **l'invio si blocca**: mai un file in chiaro da una chat con la funzione attiva.
* Apertura: `AndroidUtilities.openForView(MessageObject...)` riconosce `.pcs`, decifra in `files/cache/pcs_view` e apre con il visualizzatore di sistema; la cartella si svuota a ogni avvio.
* Limiti: niente anteprima in chat ne' riproduzione inline (e' un allegato); note vocali e video-messaggi registrati nell'app non sono ancora instradati (restano normali); sticker/GIF non cifrati.

## Pagamenti (SPENTI)
`PcFlags.STRIPE_PAYMENTS=false`, `FEE_BPS=500`. `PcPayments`: prezzi spunta (4,99 €/mese, 49,99 €/anno), commissione 5% con arrotondamento (testata), punto di integrazione PaymentSheet (carte, Google Pay, rate) che oggi risponde "disabled" senza rete. Serve un server per PaymentIntent/Subscription; la dipendenza Stripe SDK si aggiunge solo all'accensione. Flusso spunta: prima paga, poi Stripe Identity.

## Spunta blu e vantaggi
`PcVerified` alimenta `PcRanking.verifiedSource`: priorita' in Home/Esplora e "Solo verificati" in Chi puo' scrivermi. Per ora gli ID verificati si assegnano in `pc_config.xml` (`pc_verified_user_ids`). Schermata `PcVerifyActivity` (Impostazioni > Spunta blu).
